# Definition of Done

A feature is complete only when all applicable items are satisfied:

- [ ] User-facing behavior and boundaries documented.
- [ ] Typed API, IPC or tool contracts documented and versioned.
- [ ] Input validation and authorization implemented.
- [ ] Failure, timeout, cancellation and retry behavior defined.
- [ ] Logs and telemetry redact secrets and sensitive content.
- [ ] Unit tests pass.
- [ ] Integration/contract tests pass.
- [ ] Relevant UI/E2E tests pass.
- [ ] Security and privacy tests pass for risk-bearing features.
- [ ] Accessibility and keyboard behavior considered.
- [ ] Performance impact measured on reference hardware.
- [ ] Configuration and recovery documented.
- [ ] Dependency/license review completed.
- [ ] No placeholder, mock-only behavior or simulated success remains in the release path.
- [ ] Documentation and release notes updated.
